Inside `main()`, after the completion handler and before the PID-file hook, add:
```python
    # Opt-in, test-only (Phase 13): tools that exercise per-server timeouts, the result cap and
    # non-text content blocks. Behind an env flag so the default tool set — asserted exactly by
    # several tests — is unchanged.
    if os.environ.get("AGENT86_LIVE_MCP_EXTRA_TOOLS") == "1":
        import anyio
        from mcp.server.mcpserver import Audio, Image
        from mcp.types import BlobResourceContents, EmbeddedResource, ResourceLink

        @mcp.tool()
        async def sleep_for(seconds: float) -> str:
            """Sleep, then answer — the call_timeout_s probe."""
            await anyio.sleep(seconds)
            return "slept"

        @mcp.tool()
        def big_text(n: int) -> str:
            """Return n characters — the max_result_chars probe."""
            return "x" * n

        @mcp.tool()
        def tiny_image():
            """A real ImageContent block."""
            return Image(data=IMAGE_BYTES, format="png")

        @mcp.tool()
        def tiny_audio():
            """A real AudioContent block."""
            return Audio(data=AUDIO_BYTES, format="wav")

        @mcp.tool()
        def mixed_blocks():
            """Text, an embedded binary resource and a resource link in one result."""
            return [
                "before",
                EmbeddedResource(type="resource", resource=BlobResourceContents(
                    uri="res://agent86/blob.bin", mime_type="application/octet-stream",
                    blob=base64.b64encode(b"agent86-embedded-probe").decode())),
                ResourceLink(type="resource_link", name="greeting",
                             uri="res://agent86/greeting.txt", mime_type="text/plain"),
            ]
```
Add module constants `IMAGE_BYTES = b"\x89PNG\r\n\x1a\nagent86-image-probe"` and
`AUDIO_BYTES = b"RIFF\x00\x00\x00\x00WAVEagent86-audio-probe"` (importable by the test) and
`import base64` at the top. Leave tool functions without a return annotation where they return
Image/Audio/lists, so the SDK does not try to build an output schema for them. Extend the module
docstring with one sentence describing `AGENT86_LIVE_MCP_EXTRA_TOOLS`. Before moving on, verify
the round trip by hand with a scratchpad script using `MCPManager.start_server` +
`call_tool("x", "mixed_blocks", {})` and a `tiny_image` call; if the SDK rejects a return shape,
adjust the tool (e.g. return `list[ContentBlock]` explicitly) and note it in the SUMMARY.
