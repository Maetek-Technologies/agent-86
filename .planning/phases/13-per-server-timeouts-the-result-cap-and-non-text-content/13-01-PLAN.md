<objective>
Close the roadmap's stated precondition for MCP-22 — "the first plan audits the pinned corpus
before shipping the default" — by running the pinned corpus live and recording the real character
counts of its largest-output tool results, then ruling on the 8,000-char default in writing.

Ruling on research Open Question 2 (adopted): MCP-07's existing run exercised sampling/
elicitation/progress, not result sizes, so it does NOT satisfy the precondition — a fresh live run
is required. It is a Wave-1 plan that runs in parallel with the code plans because it measures
through the raw `mcp` SDK (`ClientSession` + `stdio_client`), not through agent86's
`MCPManager` — the working tree's `mcp_client.py` is being edited by 13-02 at the same time and
must not affect the measurement. It mirrors Phase 11's `11-EVIDENCE.md`: throwaway scratchpad
scripts, never committed, output recorded verbatim.

Pre-committed ruling for what the numbers can change (so the executor does not need to decide):
- If NO legitimate corpus result exceeds 8,000 chars: the default ships as ADR 0004 rules it.
- If one or more DO (expected: `read_text_file` on a large file, `git_diff`/`git_show` on a big
  commit): the default STILL ships at 8,000, per ADR 0004 — the truncation is visible (the marker
  names `max_result_chars` and the server), never silent, and the field is per-server
  overridable. Plan 13-06 documents the override with a worked example naming each tool the
  audit found over the cap. Any over-cap tool that offers NO narrowing argument (no
  head/tail/max_count/path-scoping) is listed under "Accepted risk" by name.
- If the live run is impossible (no network / npx / pip): record `**Verdict:** blocked` with the
  exact error; plan 13-06 Task 1 then stops and asks the user (checkpoint) before the docs claim
  the default was audited.

Also records MCP-25 "before" evidence: the verbatim `str(chunk)` repr today's `_content_to_text`
would produce for server-everything's `get-tiny-image` / resource-reference blocks.

Output: `13-EVIDENCE.md` only.
</objective>
