Decisions (research Pattern 3 and Pitfall 5, recorded for executor and verifier):
- One shared renderer for CallToolResult content (`render_content_block`). The Phase 11
  functions `_resource_contents_to_text` and `_prompt_messages_to_text` keep their existing marker
  text byte-for-byte (Pitfall 5 option (a)) — their tests pin that wording and they are already
  spec-compliant ("no repr"). The new renderer's binary-embedded marker deliberately reuses
  `_resource_contents_to_text`'s field order (`uri=… mime_type=… base64_len=… — not inlined`) so
  the two read the same.
- base64 is NEVER inlined, whatever its size (research anti-pattern: the cap is a size protection,
  not a permission to inline).
- `structured_content` is NOT touched (ADR 0004 scopes it out; `CAP-STRUCTURED-OUTPUT` stays out).
- Marker text for truncation follows the flight recorder's `…[truncated N chars]` shape
  (`observability/redact.py`) so both truncation markers in the codebase read alike, extended with
  the server and field so the model/user knows what to raise.
- Detection uses `isinstance` against `mcp.types` classes imported lazily inside the function
  (never at module top level — `mcp` is an optional extra); a duck-typed `.text` string is honoured
  first so existing fake-object tests keep working.

```python
"""Model-facing rendering of MCP result content (MCP-25) and the prompt-side cap (MCP-22).

Pure functions, no I/O and no top-level ``mcp`` import (it is an optional extra): the SDK's
content classes are imported lazily inside ``render_content_block``. Neither function raises —
a tool result must never raise into the loop (CLAUDE.md), so an unknown or malformed block
degrades to a named marker, never ``str(block)``.
"""

from __future__ import annotations

from typing import Any

_UNKNOWN = "unknown"


def _field(obj: Any, name: str) -> str:
    value = getattr(obj, name, None)
    return str(value) if value not in (None, "") else _UNKNOWN


def _generic(block: Any) -> str:
    try:
        kind = type(block).__name__
    except Exception:  # noqa: BLE001
        kind = "unknown"
    return f"[non-text content block: {kind} — not inlined]"


def render_content_block(block: Any) -> str:
    """One CallToolResult content block as prompt text; base64 payloads are never inlined."""
    try:
        text = getattr(block, "text", None)
        if isinstance(text, str):
            return text
        try:
            from mcp import types as mcp_types
        except ImportError:
            return _generic(block)
        if isinstance(block, mcp_types.ImageContent):
            return (f"[image content: mime_type={_field(block, 'mime_type')} "
                    f"base64_len={len(block.data or '')} — not inlined]")
        if isinstance(block, mcp_types.AudioContent):
            return (f"[audio content: mime_type={_field(block, 'mime_type')} "
                    f"base64_len={len(block.data or '')} — not inlined]")
        if isinstance(block, mcp_types.EmbeddedResource):
            res = block.resource
            header = f"embedded resource uri={_field(res, 'uri')} mime_type={_field(res, 'mime_type')}"
            if isinstance(res, mcp_types.TextResourceContents):
                return f"[{header}]\n{res.text}"
            return f"[{header} base64_len={len(getattr(res, 'blob', None) or '')} — not inlined]"
        if isinstance(block, mcp_types.ResourceLink):
            return (f"[resource link uri={_field(block, 'uri')} name={_field(block, 'name')} "
                    f"mime_type={_field(block, 'mime_type')} size={_field(block, 'size')}]")
        return _generic(block)
    except Exception:  # noqa: BLE001 - never raise into the loop
        return _generic(block)


def truncate_result(text: str, limit: int, server: str) -> str:
    """Cut ``text`` at ``limit`` chars with a visible marker (ADR 0004) — never drop, never raise."""
    limit = max(0, int(limit))
    if len(text) <= limit:
        return text
    dropped = len(text) - limit
    return (
        f"{text[:limit]}\n…[truncated {dropped} chars: result exceeded max_result_chars={limit} "
        f"for MCP server '{server}'; raise max_result_chars under [mcp.servers.{server}] "
        f"to see more]"
    )
```
