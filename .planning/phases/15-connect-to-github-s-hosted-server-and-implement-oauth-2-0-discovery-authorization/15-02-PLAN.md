*reference* to the client secret, validation that names the fix, a write-back guard widened to

transport or flow code — that is 15-03/15-04. Runs in parallel with 15-03 (disjoint files).

`MCPServerConfig`, not a new transport (research Pattern 1). The redirect port default comes from
15-EVIDENCE.md's F2 ruling (`8765` unless F2 says otherwise — use F2's value).
