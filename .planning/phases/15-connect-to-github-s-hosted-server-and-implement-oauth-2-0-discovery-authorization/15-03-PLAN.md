<objective>
Build the OAuth pieces as one new, lazily-imported module, `src/agent86/tools/mcp_oauth.py`,
test-first. It wraps the installed SDK's `OAuthClientProvider` (research: "don't hand-roll" —
discovery, PKCE, state and iss checks are the SDK's) and supplies only what agent86 must own:
a pre-seeded in-memory token store (GitHub has no DCR), a fixed-port loopback callback, a
browser-open redirect handler, a scope override, and an `Accept: application/json` wrapper
(15-EVIDENCE.md F1). Parallel with 15-02: this module takes plain arguments, never
`MCPServerConfig`, so it does not need 15-02's fields.

The module is imported ONLY from function bodies in `mcp_client.py` (plan 15-04), so it may import
`mcp`/`httpx2` at its own top level — `run`/`--plain` never reach it unless a server sets
`auth = "oauth"`. It must not import textual, keyring or tomlkit. Storage is in memory only this
phase; MCP-18 swaps a keyring-backed class implementing the same SDK `TokenStorage` Protocol, and
MCP-19 swaps the redirect/callback pair for a headless flow — `build_oauth_auth` takes both as
parameters so neither needs an interface change.
</objective>

REDIRECT_HOST: str = "127.0.0.1"      # 15-EVIDENCE.md F2 (use "localhost" only if F2 says so)
REDIRECT_PATH: str = "/callback"

class MCPAuthorizationError(RuntimeError): ...

def redirect_uri(port: int) -> str                 # f"http://{REDIRECT_HOST}:{port}{REDIRECT_PATH}"

class InMemoryTokenStorage:                         # satisfies mcp.client.auth.TokenStorage
    def __init__(self, client_info: OAuthClientInformationFull) -> None
    async def get_tokens(self) -> OAuthToken | None
    async def set_tokens(self, tokens: OAuthToken) -> None
    async def get_client_info(self) -> OAuthClientInformationFull | None
    async def set_client_info(self, client_info: OAuthClientInformationFull) -> None
    @property
    def client_id(self) -> str
    @property
    def has_tokens(self) -> bool
    def update_client_info(self, client_info: OAuthClientInformationFull) -> None   # sync; keeps tokens
    def __repr__(self) -> str   # "InMemoryTokenStorage(client_id='Ov23…', has_tokens=True)" — never token/secret

def build_client_info(*, client_id: str, client_secret: str | None, redirect_port: int,
                      scopes: list[str] | None) -> OAuthClientInformationFull

def override_scope(authorization_url: str, scopes: list[str] | None) -> str

class LoopbackCallback:
    def __init__(self, port: int, *, server: str) -> None
    async def start(self) -> None
    async def wait(self, timeout: float) -> AuthorizationCodeResult
    async def close(self) -> None

class AcceptJSONAuth(httpx2.Auth):
    requires_response_body = True
    def __init__(self, inner: httpx2.Auth) -> None

def build_oauth_auth(*, server: str, server_url: str, storage: TokenStorage, redirect_port: int,
                     scopes: list[str] | None, callback_timeout_s: float,
                     notify: Callable[[str], None],
                     open_browser: Callable[[str], bool] | None = None) -> httpx2.Auth

  <implementation>
Module layout for `src/agent86/tools/mcp_oauth.py` (module docstring: purpose, the lazy-import
rule, "in memory only — MCP-18 persists, MCP-19 adds headless", and why the port is fixed):

- Imports at top: `asyncio`, `logging`, `sys`, `from collections.abc import AsyncGenerator, Callable`,
  `from urllib.parse import parse_qs, parse_qsl, urlencode, urlsplit, urlunsplit`, `import httpx2`,
  `from mcp.client.auth import OAuthClientProvider, TokenStorage`,
  `from mcp.shared.auth import AuthorizationCodeResult, OAuthClientInformationFull, OAuthClientMetadata, OAuthToken`,
  `from agent86.secrets import redact`. NO textual/keyring/tomlkit. `webbrowser` is imported inside
  `_open_browser` only.
- `_GRANT_TYPES = ["authorization_code", "refresh_token"]`.
- `build_client_info`: as behavior; do NOT set `issuer` — comment citing `utils.py`
  `credentials_match_issuer` (a None issuer is never discarded, so the SDK never falls back to DCR).
- `InMemoryTokenStorage`: two private attributes `_client_info`, `_tokens`; `__repr__` per contract.
- `override_scope`: `urlsplit` -> `parse_qsl(keep_blank_values=True)` -> replace/add `scope` with
  `" ".join(scopes)` -> `urlencode` -> `urlunsplit`. `None` or empty list returns the input unchanged.
- `LoopbackCallback`: `start()` = `asyncio.start_server(self._handle, REDIRECT_HOST, port)`; on
  `OSError` raise `MCPAuthorizationError(f"MCP server '{server}': cannot listen for the OAuth redirect on {redirect_uri(port)} ({exc}); free that port or set oauth_redirect_port under [mcp.servers.{server}] (and register the same callback URL with the OAuth App)")`.
  `_handle(reader, writer)`: read the request line (`await reader.readline()`, bounded to 8 KiB)
  and drain headers until a blank line; parse the path; if path != `REDIRECT_PATH` write `404` and
  return; else parse the query with `parse_qs`; write `HTTP/1.1 200 OK`, `Content-Type:
  text/html; charset=utf-8`, `Connection: close`, and a short body ("agent86: authorization
  received — you can close this tab and return to agent86." or, for an error, "agent86:
  authorization failed — <error>"); set the future's result/exception once (ignore later hits).
  `wait(timeout)` = `asyncio.wait_for(asyncio.shield(self._future), timeout)`; on
  `TimeoutError` raise `MCPAuthorizationError(f"MCP server '{server}': no authorization callback on {redirect_uri(port)} within {timeout:g}s (oauth_callback_timeout_s) — finish signing in in the browser, or raise oauth_callback_timeout_s under [mcp.servers.{server}]")`.
  An `error` param raises `MCPAuthorizationError(f"MCP server '{server}': authorization was refused by the server ({error}: {error_description})")`.
  `close()`: `server.close(); await server.wait_closed()`, guarded for double-close.
- `AcceptJSONAuth(httpx2.Auth)`: `requires_response_body = True`; `async_auth_flow(request)`:
  ```python
  flow = self._inner.async_auth_flow(request)
  try:
      outgoing = await flow.__anext__()
      while True:
          if "accept" not in outgoing.headers:
              outgoing.headers["Accept"] = "application/json"
          response = yield outgoing
          outgoing = await flow.asend(response)
  except StopAsyncIteration:
      return
  ```
  Docstring cites 15-EVIDENCE.md F1 (GitHub form-encodes its token response without Accept, and the
  SDK parses JSON only — a parse failure's message could even carry the token).
- `_open_browser(url) -> bool`: `import webbrowser`; `return bool(webbrowser.open(url))`; any
  exception -> `False`.
- `build_oauth_auth`: one `LoopbackCallback` per authorization attempt, created inside the
  redirect handler. `redirect_handler(url)`: `url = override_scope(url, scopes)`;
  `listener = LoopbackCallback(redirect_port, server=server); await listener.start()`; keep it in
  a closure cell; `opened = await asyncio.to_thread(opener, url)` (opener = `open_browser or
  _open_browser`, exceptions -> False); if opened: `notify(f"MCP server '{server}' needs authorization — complete it in the browser window that just opened (waiting up to {callback_timeout_s:g}s).")`
  else: message `f"MCP server '{server}' needs authorization — open it in a browser: {url}"`,
  passed to `notify` AND written to `sys.stderr` (one line + flush; stderr, never stdout, so
  `run --json` stdout stays clean). `callback_handler()`: `try: return await
  listener.wait(callback_timeout_s) finally: await listener.close()`. Construct
  `OAuthClientMetadata(redirect_uris=[redirect_uri(redirect_port)], token_endpoint_auth_method=
  "client_secret_post", grant_types=_GRANT_TYPES,
  client_name="agent86", scope=" ".join(scopes) if scopes else None)` and return
  `AcceptJSONAuth(OAuthClientProvider(server_url=server_url, client_metadata=..., storage=storage,
  redirect_handler=redirect_handler, callback_handler=callback_handler))`. (The metadata's auth
  method only feeds DCR, which never runs; the token request uses the pre-seeded client record's
  own method — `prepare_token_auth` reads `client_info`.) Every message passed
  to `notify` or put in an exception goes through `redact(...)`.
