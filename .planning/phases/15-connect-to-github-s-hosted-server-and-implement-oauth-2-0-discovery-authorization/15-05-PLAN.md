  where `_Verifier.verify_token(t)` returns `AccessToken(token=t, client_id=CLIENT_ID, scopes=["repo"])`
  only if `t == ACCESS_TOKEN`, else `None`. One tool: `whoami() -> str` returning `"oauth-ok"`.
- `app = mcp.streamable_http_app()`; add Starlette `Route`s to `app.router.routes` (insert at the

    (`authorization_endpoint = issuer + "/authorize"`, `token_endpoint = issuer + "/access_token"`),
    no `registration_endpoint`.
  - `GET /login/oauth/authorize`: 400 text `redirect_uri mismatch` unless
    `redirect_uri == f"http://127.0.0.1:{redirect_port}/callback"` exactly (GitHub's exact-match
    rule); 400 unless `client_id == CLIENT_ID` and `code_challenge_method == "S256"`; record
    `scope`, `resource`, `code_challenge_method` into stats; if `DENY_SCOPE` is in the scope list,
    302 to `redirect_uri?error=access_denied&error_description=The+user+denied&state=<state>`;
    else mint a random code bound to `(code_challenge, redirect_uri)` and 302 to
    `redirect_uri?code=<code>&state=<state>&iss=<urlencoded issuer>`; stats `authorize_hits += 1`.
  - `POST /login/oauth/access_token` (form body): record the `Accept` header into stats
    `token_accept`; if `client_secret != CLIENT_SECRET` -> 200 JSON
    `{"error": "incorrect_client_credentials"}` (GitHub answers errors with 200); verify the code
    exists, `redirect_uri` matches, and `base64url(sha256(code_verifier)) == code_challenge`
    (no padding) else 200 `{"error": "bad_verification_code"}`; on success, if `Accept` contains
    `application/json` return JSON `{"access_token": ACCESS_TOKEN, "token_type": "bearer", "scope": "repo"}`,
    otherwise return `application/x-www-form-urlencoded` body
    `access_token=<ACCESS_TOKEN>&scope=repo&token_type=bearer` (GitHub's default).
  - `POST /login/oauth/register` -> 422 `text/html` body `<html>Unprocessable</html>`; stats
    `register_hits += 1`. Also count any request path ending `/register` the same way.
- Stats: a dict persisted as JSON to `stats_file` after every event (the test process reads it).
- `uvicorn.run(app, host="127.0.0.1", port=port, log_level="warning")`.
