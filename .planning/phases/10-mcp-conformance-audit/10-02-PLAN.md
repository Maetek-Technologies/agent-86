from agent86.config import MCPServerConfig
from agent86.tools.mcp_client import MCPManager

cfg = MCPServerConfig(
    command="npx",
    args=["-y", "@modelcontextprotocol/server-everything@2026.8.31"],
)
manager = MCPManager({})
try:
    tools = manager.start_server("everything", cfg, timeout=180.0)

Three notes that will save a debugging cycle:

- `MCPManager` marshals onto its own loop; call `manager.close()` in a `finally` or the process hangs.
