<objective>
Make `context_window_for` learn an OpenRouter model's real context window from OpenRouter's
`GET {base_url}/models` (`data[].context_length`) instead of guessing from the model name
(today `openrouter:qwen/qwen3.7-max` -> 32768 via the generic `("qwen", 32_768)` row).

New resolution order: `[model.context_window]` override > OpenRouter-reported `context_length`
(provider section is `openrouter` OR its `base_url` host is/ends with `openrouter.ai`) > existing
provider rules (ollama/llamacpp) > `_CONTEXT_WINDOWS` table > `DEFAULT_CONTEXT_WINDOW`.

Purpose: the conversation budget and status gauge use the real window for hosted models.
Output: new `cognitive/remote_windows.py`, a context-length fetcher in `catalog.py`, wiring in
`capabilities.py`, tests, docs + CHANGELOG.
</objective>
